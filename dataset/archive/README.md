# Archived evaluation inputs

`tasks_v1.json` is the exact JSON input from upstream revision
`baa36626340edfd2045449864dac7fbc8f041327`, used for the archived 120-cell run.
The current dataset is version 1.1. It retains 30 tasks, 201 specification
entries and 112 scenario descriptions, with two corrected formulas and an
explicit P04 observation convention.

`runtime_suites_v1/P01.json`, `P04.json` and `P07.json` retain the pre-update
vectors. For the historical runtime summary, use these three files and the
unchanged current vectors for the other tasks. Source hashes in historical
Windows logs use CRLF; Git archive text uses LF.
